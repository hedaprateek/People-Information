Materials

Upload a document (PDF, Word, Excel, PowerPoint, image) into the materials/ folder. It is committed straight away, and a row is added to your Documents sheet — press Publish afterwards to put that row live. Needs the GitHub token below.

Publishing

Publishing writes data.xlsx straight to your GitHub repository, and the live site updates within a minute. It needs a token with permission to write to that one repo. The token is kept in this tab only — never saved to the page or the repo.

How do I create the token?
  1. GitHub → your avatar → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access → Only select repositories → pick People-Information
  4. Under Permissions → Repository permissions, set Contents to Read and write
  5. Generate, copy, and paste it above. If you skip this, use Export to Excel and upload the file to GitHub by hand instead.
